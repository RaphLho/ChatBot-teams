Token
Unité de découpage du texte utilisée par les modèles de langage (environ 3/4 de mot en moyenne). Chaque question posée et chaque réponse générée consomment des tokens.
Tokens de prompt
Tokens envoyés AU modèle : la question de l'étudiant, l'historique de conversation récent et les extraits de cours injectés pour le contexte (RAG).
Tokens de complétion
Tokens générés PAR le modèle pour produire sa réponse. Généralement plus coûteux par token que les tokens de prompt.
mistral-small-latest
Modèle de langage utilisé pour générer les réponses conversationnelles. Coût : ~0.20 €/1M tokens prompt, ~0.60 €/1M tokens complétion.
mistral-embed
Modèle d'embedding utilisé pour vectoriser les documents et les questions (recherche sémantique RAG). Coût : ~0.10 €/1M tokens.
Session vs Global
Session = depuis le dernier redémarrage du serveur. Global = cumul depuis le tout premier lancement, sauvegardé sur disque.
Coût estimé
Calculé avec les tarifs Mistral détaillés par modèle. C'est un ordre de grandeur indicatif, pas une facture exacte.
Requête hors-sujet ([NON-CONFORME])
Le bot préfixe sa réponse par [NON-CONFORME] quand la question sort du cadre pédagogique. Cette balise est retirée avant affichage mais comptabilisée.
Sans réponse ([SANS_REPONSE])
Le bot préfixe sa réponse par [SANS_REPONSE] quand aucun document ne permet de répondre à la question (formule de repli). Cette balise est retirée avant affichage mais comptabilisée, et signalée par un badge ambre dans l'historique des requêtes.
Cache RAM
Le bot mémorise les réponses durant la session. Si la même question revient, la réponse est renvoyée instantanément sans nouvel appel API.
Blocs vectoriels (chunks)
Les documents sont découpés en blocs d'environ 600 caractères, puis transformés en vecteurs numériques (embeddings) pour la recherche sémantique.
